# にこまる美容室 顧客カルテ管理アプリ(ローカル版)

ネットには一切つながらない、**完全にローカル(オフライン)** で動く顧客管理ソフトです。
お客様の基本情報・来店履歴・カルテ情報(髪質やアレルギーなど)・雑談メモを、
お店のパソコンの中(または共有フォルダ)だけに保存します。

Webサイトの予約システム(Firebase)とは完全に別管理です。データはつながっていません。

## できること

- 顧客の基本情報(お名前・フリガナ・電話番号・生年月日)の登録・編集・削除
- 来店履歴(来店日・メニュー・担当・メモ)の記録
- カルテ情報(髪質・薬剤配合・アレルギー)の記録
- 雑談メモ(趣味・ご家族・お仕事・ペット・好きな話題・自由メモ)の記録
- お名前・フリガナ・電話番号での検索
- CSVエクスポート(Excelで見られる形式でのバックアップ)
- 起動時パスワード(任意・個人情報保護のため)
- 複数のパソコンで同じデータを見る(共有フォルダにデータベースファイルを置く方式)

## 動作の仕組み(初心者向け解説)

- `app.py` … 画面(ボタンや入力欄)を作っているファイル
- `db.py` … データの読み書き(保存・検索・削除)を行うファイル
- `config.py` … 「データベースファイルがどこにあるか」を覚えておくファイル
- データは全部 **1つの `.db` ファイル**(SQLiteという形式)の中に入ります。難しい設定は不要です。

## 使い方(パソコンにPythonを入れて動かす方法)

### 1. Pythonをインストールする(まだ入れていない場合)

1. https://www.python.org/downloads/ からWindows用のインストーラーをダウンロード
2. インストール画面で、**必ず「Add python.exe to PATH」にチェック**を入れてから「Install Now」
   - Windows用インストーラーには `tkinter`(画面を作る部品)も最初から含まれているので、追加のインストールは不要です。

### 2. アプリを起動する

**まずZIPを右クリックして「すべて展開」し、フォルダを取り出してから**使ってください
(ZIPの中身を展開せずに直接実行すると、動かないことがあります)。

展開したフォルダ(`customer-app`)の中にある **`run.bat` をダブルクリック**するだけです。

黒い画面(コンソール)が一緒に開きますが、これは異常ではありません。アプリの裏側の状態を表示するための
ものなので、閉じずにそのままにしておいてください(閉じるとアプリも終了します)。この黒い画面の文字は
あえて英語表示にしています(理由は下のトラブルシューティングを参照)。アプリ本体の画面はもちろん日本語です。

- 初回起動時に「データベースの場所」を聞かれます。
  - 1台のパソコンだけで使う → 「いいえ」を選び、わかりやすい場所(デスクトップなど)に保存
  - すでに他のパソコンで使っている → 「はい」を選び、共有フォルダの中のファイルを選択
- 続けて「起動パスワードを設定しますか?」と聞かれます。個人情報を扱うため設定をおすすめします(あとから「設定」メニューでも変更できます)。

### うまく起動しない場合(トラブルシューティング)

- **黒い画面が一瞬だけ表示されて、すぐ消えてしまう**
  - `run.bat` は、実行した内容を**すべて `run_debug.log` というファイルに記録**しながら動きます。
    画面が一瞬で消えて読めなくても、この `run_debug.log` を後から開けば、どこまで進んで
    何が起きたのかが分かるようになっています。まずはこのファイルの中身をこちらに教えてください。
    (ファイルが1つもできていない場合は、`run.bat` 自体が実行されていない可能性が高いです。
    ZIPを展開せずに直接開いていないか、セキュリティソフトにブロックされていないかを確認してください。)
  - `run.bat` は、エラーが出た場合は画面が自動で閉じないように「何かキーを押すまで待つ」ようにも
    なっていますが、`run_debug.log` の方が確実です。
  - `[ERROR] Python was not found` と出た場合は、上の「1. Pythonをインストールする」の手順で
    「Add python.exe to PATH」にチェックを入れ忘れていないか確認し、入れ忘れていた場合はPythonを
    再インストールしてください。
  - **OneDriveの「デスクトップ」フォルダなど、クラウド同期されている場所**にこのフォルダを置いている場合、
    同期の影響でうまく動かないことがあります。試しに、このフォルダを `C:\` 直下など、同期されていない
    場所(例: `C:\NikomaruApp`)にコピーしてから実行してみてください。

### 3. 複数のパソコンで使う場合(スタッフ共有)

1. 1台目のパソコンで、共有フォルダ(例: 店内LANの共有フォルダ、USBメモリなど)を保存先に選んで新規作成
2. 2台目以降のパソコンでは、初回起動時に「はい(既存のファイルを選ぶ)」を選び、同じファイルを指定

**注意**: SQLite(このアプリが使っているデータベース形式)は、ネットワーク越しの共有フォルダでの
複数人同時アクセスにそこまで強くありません。「同じお客様のデータを、複数のスタッフが全く同じ瞬間に
保存しようとする」ようなケースはまれに保存が失敗することがあります(その場合はもう一度保存し直せば
大丈夫です)。日常的な使い方(別々のお客様を別々のタイミングで入力する)では問題になりにくいですが、
より確実性を求める場合は、来店時にその場にいる担当スタッフだけが入力する運用にすることをおすすめします。

**データベースファイルの保存場所について**: OneDriveの「デスクトップ」など、クラウドに自動同期される
フォルダの中にデータベースファイルを置くのは避けてください。同期のタイミングでファイルがロックされ、
保存に失敗したりデータが壊れたりする可能性があります。店内LANの共有フォルダなど、クラウド同期が
かかっていない場所を選んでください。

## Windowsアプリ(.exe)にする方法

`run.bat` で動かすだけでも問題なく使えますが、「.exeファイルとしてダブルクリックで起動したい」場合は、
このフォルダの **`build_exe.bat` をダブルクリック**してください。自動でPyInstallerをインストールし、
`dist` フォルダの中に `NikomaruSalonKarte.exe` を作成します(ファイル名はアルファベットにしていますが、
気になる場合はWindowsのエクスプローラー上でファイル名を右クリック→名前の変更すれば、日本語名に変えても
問題なく動きます)。

**重要**: この `.exe` 化の作業は、**実際にお使いのWindowsパソコン上で行ってください**。
(このアプリを開発した環境はWindowsではないため、こちらで.exeファイルそのものを作って
お渡しすることができません。`build_exe.bat` を使えば、どなたでも数分で作成できます。)

作成した `.exe` ファイルは、`app.py` ・ `db.py` ・ `config.py` と同じフォルダに置いたまま使ってください。

## セキュリティ・プライバシーについて

- このアプリは**ネットに一切通信しません**。データは指定した `.db` ファイルの中にだけ存在します。
- 起動パスワードは、うっかり他の人に画面を見られることを防ぐための**簡易的な**ものです。
  `.db` ファイル自体は暗号化されていないため、ファイルそのものへのアクセス権(共有フォルダの権限設定など)も
  あわせて管理してください。
- 定期的に「ファイル」メニューの「CSVエクスポート」でバックアップを取ることをおすすめします。
  `.db` ファイル自体をコピーして保管するのも有効なバックアップです。
- `.db` ファイルやCSVファイルは、**絶対にこのGitリポジトリの中に置いたりコミットしたりしないでください**
  (`.gitignore` で除外はしていますが、念のため保存場所は必ずこのフォルダの外、共有フォルダなど別の場所にしてください)。
